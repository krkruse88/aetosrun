# Aetos:run support

Aetos:run is an interval run timer for iPhone. If something isn't working or you have a question, we're happy to help.

## Common questions

### How do I restore my Pro purchase?
Open Aetos:run, go to **Settings → Aetos:run Pro**, and tap **Restore purchases**. You need to be signed in with the Apple ID you used to buy it. Purchases are handled by Apple, so they also carry over to a new iPhone.

### How does the free trial work?
You can try every Pro feature free for 14 days. When the trial ends, Aetos:run keeps working with the 3 free themes and all core features. Only the Pro features turn off: the extra themes, matching app icons, theme-colored trails, saving runs to Apple Health, and automatic iCloud backup. Pro is a one-time purchase, not a subscription.

### Will I lose my runs if I delete the app?
Deleting an app on iPhone removes its data. To keep your runs safe:

- In **Settings → Backup**, tap **Backup folder** and pick a folder in the Files app, for example in iCloud Drive. Aetos:run then saves a backup there after every run of a minute or more. The backup survives deleting the app.
- After reinstalling, open **Settings → Backup → Backup folder**, pick the same folder, and tap **Restore** when Aetos:run offers it. Only runs that are missing are added.
- You can also tap **Back up now** to save a backup file anywhere, and **Restore from a backup** to load one.

### Weather or location isn't showing.
Check **Settings → Privacy & Security → Location Services → Aetos:run** and choose "While Using the App". Weather needs an internet connection. In Aetos:run, **Settings → Preferences → Weather from my location** must be on.

### I'm not getting alerts when the screen is locked.
- Make sure **Sound** or **Vibrate at each change** is on in Aetos:run Settings, and that your iPhone isn't in silent mode or a Focus that blocks notifications.
- Allow notifications in **Settings → Notifications → Aetos:run**.
- Keep Aetos:run running in the background. Don't force-quit it during a run.
- For the Lock Screen timer, make sure Live Activities are allowed in **Settings → Aetos:run**.

### How do I save runs to Apple Health?
This is a Pro feature. Turn on **Settings → Preferences → Save runs to Apple Health** and allow Workouts and Routes when asked. Each finished run of at least 30 seconds is added to Health as a running workout, with distance and route. Aetos:run only writes to Health. It never reads your Health data.

### How do I delete my data?
Swipe to delete a run in History. Deleted runs stay in **Recently Deleted** for 14 days, then they are removed for good. Deleting the app removes everything else stored in it. Backup files you saved to Files or iCloud Drive are yours to delete there.
